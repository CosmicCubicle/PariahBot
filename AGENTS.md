# PariahBot

Discord bot built with Discord.js. This file is the entry point for anyone
working on the repo, whether a person or an AI tool.

**Read all of the files below before changing code.** They are the source of
truth. Add new guidance to the matching file, not here.

- @ProjectContext.md: what the project is, its constraints, and past decisions
- @WorkingAgreements.md: the hard rules (state, guild isolation, destructive actions, never publishing a real bot instance, never fetching a user-supplied address directly). These override everything else.
- @CodeStandards.md: day-to-day style, structure, testing and PR conventions
- @Team.md: who maintains this repo and who the bot is for
- @References.md: wiki links, the bots features are modeled on, and files to copy from
